# Palm Bay Resort Phu Quoc

Premium, image-led Next.js remake for Palm Bay Resort Phu Quoc.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Stack

- Next.js 16 + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React
- Next/Image

## Real property content

The page uses current public Booking.com property information: address in Cua Lap/Duong To, Phu Quoc; room categories; pool, spa, restaurant, breakfast, airport shuttle, parking and Wi-Fi; and the currently displayed guest rating data.

Booking CTA points to the public Booking.com property listing for live rates and availability.

## Photography

The initial image URLs are Booking.com CDN assets used to match the actual property imagery. For a commercial hotel deployment, replace these with property-owned/licensed originals and confirm permission for reuse.
